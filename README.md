# AlSaqarAccountingV4

نظام محاسبي وERP مبني على **.NET Framework 4.8 / WinForms**.

## حالة المشروع

هذا المستودع مخصص لتطوير وتشغيل النظام ومكوناته البرمجية. يجب اختبار أي تغيير على نسخة اختبار قبل استخدامه مع بيانات محاسبية حقيقية.

## الوثائق والسياسات

- SECURITY.md — سياسة الأمان والإبلاغ عن الثغرات.
- LICENSE — شروط استخدام وتوزيع الكود المملوك للمشروع.
- CONTRIBUTING.md — قواعد المساهمة ومعايير التغيير.
- SUPPORT.md — إرشادات طلب الدعم.
- CODE_OF_CONDUCT.md — قواعد السلوك.
- .github/ISSUE_TEMPLATE — قوالب بلاغات الأخطاء وطلبات الميزات.
- .github/pull_request_template.md — قائمة تحقق لمراجعة Pull Requests.

## الأمان

لا تضع داخل المستودع كلمات مرور SQL Server أو Connection Strings تحتوي على أسرار أو مفاتيح API أو بيانات العملاء الحقيقية.

## الترخيص

الكود الأصلي للمشروع ملكية خاصة. راجع ملف LICENSE قبل إعادة الاستخدام أو التوزيع.

المكونات الخارجية تبقى خاضعة لتراخيصها الخاصة.

## البناء

المشروع يستهدف **.NET Framework 4.8**. استخدم إعداد Release وPlatform Any CPU عند التحقق من البناء.
