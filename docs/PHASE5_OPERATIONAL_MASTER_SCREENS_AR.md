# Phase 5 — الشاشات التشغيلية الأساسية

هذه المرحلة تحول مجموعة الشاشات الأساسية التي ظهرت في قائمة الصلاحيات إلى شاشات بيانات تشغيلية فعلية بدل شاشة الـfallback العامة.

## الشاشات الأولى
- الشركات → `Item_Company`
- الوحدات → `Item_Unit`
- الفئات → `Item_Class`
- المجموعات → `Item_Groups`
- الأصناف → `Get_All_Items`
- شجرة الحسابات / الحسابات → `Get_Account_Tree`
- العملاء → `Select_AccountCustomer @BranchID`
- الموردون → `Account_CustSup`
- الفروع → `Account_Branch`
- المبيعات → `Select_Order_Orders @BranchID`
- المشتريات → `Select_Order_Purchases @BranchID`

## قاعدة التنفيذ
الشاشات التي لها Stored Procedure مُثبت في كتالوج الإجراءات تستخدم الإجراء الأصلي للقراءة. الشاشات التي لا يوجد لدينا لها عقد قراءة مؤكد تستخدم SELECT للجدول المسموح به فقط.

لا تنفذ هذه المرحلة عمليات INSERT/UPDATE/DELETE/TRUNCATE. أزرار الحفظ والتعديل والحذف تبقى معروضة حسب الصلاحية لكن غير مفعلة حتى يتم استخراج عقد الإجراء الأصلي للشاشة.

## الصلاحيات
يبقى `User_Screens + User_Permission + User_Groups` مصدر صلاحية الفتح. تظهر صلاحيات الحفظ والتعديل والحذف والطباعة والتصدير وتبديل الفرع في رأس الشاشة، بينما لا يُنفذ أي تغيير في قاعدة البيانات من هذه الطبقة.
